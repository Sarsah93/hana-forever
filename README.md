# Hana Forever 🐩

갈색 토이푸들 **하나**가 Windows 작업 표시줄 위에서 걷고, 창에 기대고, 점프하고, 엎드려 쉬고, 가끔 간식을 조르는 데스크톱 동반자입니다.

## 실행

```powershell
npm install
npm run tauri dev
```

`npm run dev`는 브라우저 안의 미리보기입니다(가상 2모니터·가상 브라우저 창·작업 표시줄, 패널은 페이지 안에 표시). Windows 데스크톱 창·작업 표시줄·여러 모니터에 실제로 반응하려면 `npm run tauri dev`를 사용하세요.

```powershell
npm test            # 물리·행동 회귀 테스트 31개
npm run build       # tsc + vite (하나 창 + 액션 패널 두 페이지)
npm run tauri build # 설치 파일 (릴리스 빌드는 콘솔 창 없이 실행)
```

빌드 준비와 설치 파일 위치는 [docs/BUILD.md](docs/BUILD.md)에 있습니다.

## 현재 동작

- 테두리·그림자 없는 투명 창, 트레이 메뉴. **하나 몸과 풍선 위에서만 마우스를 받고 나머지 영역은 바탕화면으로 클릭이 통과**합니다.
- 작업 표시줄 윗면을 바닥으로 좌우 보행. **모니터 사이를 걸어서 넘어가고**, 바닥 높이가 다르면 내려서 뛰거나 살짝 뛰어오릅니다.
- 실제 창의 측면 충돌·윗면 착지·아랫면 점프 충돌, 창 옆 두 앞발 기대기, 점프·낙하·착지, 드래그 후 떨어지기.
- 자율 행동: 걷기·서 있기·점프·**두 발 서기**·털기·턱 긁기, 그리고 **쉬기**(앉기·엎드리기·엎드려 쉬기·뒤돌아보기·웅크리기·하품)가 전체의 40%쯤. 웅크린 채 되새김질도 합니다.
- **요구 생각 풍선**: 간식(뼈)·장난감(공)·쓰다듬기(손바닥)를 여유 있는 쪽에 띄우고 두 발로 서서 조릅니다. 점심·퇴근 시간에는 벽시계 풍선.
- **쓰다듬기**: 머리 위에서 마우스를 살살 문지르면 엎드려 가만히 있다가, 2초 넘게 이어지면 눈을 감고 웃습니다(엎드린 방향 유지). 패널의 교감 탭(쓰다듬기·간식 주기·놀아주기)으로도 반응합니다.
- **커서 바라보기**: 커서가 가까이에서 움직이면 옆으로 앉아 커서 쪽을 보고, 위에 있으면 고개를 듭니다.
- **집중 모드(방해 금지)**: 창을 피해 빈 곳에 조용히 엎드리고, 자리가 없으면 숨었다가 자리가 나면 돌아옵니다. 끄면 빈 자리로 랜덤 복귀.

## 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 액션 패널 열기/닫기 | 하나 **우클릭**, **F2**(하나 창에 포커스가 있을 때), 트레이 메뉴 |
| 패널 옮기기 / 따라오게 하기 | 제목줄 드래그 / 제목줄의 **따라가기** 버튼 |
| 걷기 · 점프 | ← → / Space, 더블클릭 |
| 옮기기 | 하나를 드래그하고 놓기 |
| 점심·퇴근 시간, 집중 모드 | 패널 **설정** 탭 또는 트레이 메뉴 |
| 작업 표시줄 위로 데려오기 · 종료 | 트레이 메뉴 |

패널 탭: **제자리 · 왼쪽 · 오른쪽 · 뒤 · 교감 · 설정**. 제자리의 "서 있기"는 네 발 서기, "쉬기"는 휴식 자세 중 하나를 골라 줍니다. 교감의 말 걸기는 자리만 준비되어 있습니다.

## 아트

- `motion-v2`: 대기·걷기·기대기·점프 16키포즈 아틀라스.
- `motion-v3`: 정면 털기, 엎드리기, 뒤돌아보기, 턱 긁기(앉기 포함), 하품(웃기 포함), 웅크리고 되새김질 — 6장의 생성 시트를 `tools/sprites/extract.cjs`로 키잉·패킹. 크기 정합은 [docs/previews/size-calibration.png](docs/previews/size-calibration.png).
- 서 있는 자세의 웃는 표정과 고개만 돌리는 프레임은 아직 없어 후속 제작 대상입니다.
