하나 사용법 가이드

갈색 토이푸들 하나는 작업 표시줄 위에서 사는 데스크톱 친구예요. 스스로 돌아다니고, 창에 기대고, 모니터를 건너다니고, 가끔 뭔가를 조르기도 해요. 이 창은 Esc로 닫아요.

하나는 이런 친구기본 조작액션 패널교감과 생각 풍선설정트레이 메뉴창과 모니터집중 모드자동 실행문제 해결단축키 요약

하나는 이런 친구예요

  • 바닥은 작업 표시줄 윗선이에요. 창 위에 올라설 수도 있고, 밟고 있던 창이 사라지면 떨어져서 착지해요.
  • 스스로 돌아다녀요. 걷기·서 있기·두 발 서기·점프·털기·턱 긁기, 그리고 앉기·엎드리기·엎드려 쉬기·뒤돌아보기·웅크리기·하품 같은 휴식 자세를 섞어 지내요. 시간의 40% 정도는 쉬어요.
  • 창 옆면은 벽이에요. 걷다가 창에 닿으면 두 앞발을 창에 기대고, 잠시 뒤 돌아서요. 창이 움직이거나 최소화되면 기대기를 풀어요. 화면에 실제로 보이는 창만 벽으로 쳐요 — 다른 창 뒤에 가려진 부분엔 부딪히지 않아요.
  • 모니터 두 대 이상이면 맞닿은 모니터 사이를 걸어서 오가요. 옆 모니터 바닥이 낮으면 뛰어내리고, 높으면 뛰어올라요. 화면 바깥쪽 가장자리는 넘어가지 않아요.
  • 항상 맨 위에 있지만, 하나 몸 밖의 투명한 부분은 클릭이 그대로 뒤의 창으로 통과해요. 작업에 방해가 되지 않아요.
  • 동작이 바뀔 때 갑자기 끊기지 않도록, 엎드린 자세에서 일어날 땐 앉기를 거치고, 웅크린 자세에선 몸을 일으키는 장면을 먼저 보여줘요.

액션 패널

하나 옆에 뜨는 작은 리모컨이에요. 제목줄을 드래그해서 옮기고, 따라가기를 켜면 하나가 움직일 때 같이 따라가요. 패널로 시킨 동작은 25초 동안 자율 행동보다 우선해요.

설정아래 설정 참고

아래 상태줄에는 지금 동작 · 방향 · 접지 여부와, 풍선이 떠 있으면 무엇을 원하는지가 보여요.

교감과 생각 풍선

  • 2.5~5.5분마다 간식 · 장난감 · 쓰다듬기 중 하나를 원해요. 머리 옆에 생각 풍선이 60초 동안 뜨고, 그동안 두 발로 서서 졸라요.
  • 교감 탭에서 원하는 걸 주면 반응해요: 쓰다듬기 → 엎드려 웃기 · 간식 → 웅크리고 되새김질 · 놀아주기 → 점프 후 털기. 기다리던 것이면 상태줄 문구가 달라져요.
  • 풍선이 없어도 언제든 교감할 수 있어요.
  • 점심 · 퇴근 시각이 되면 벽시계 풍선이 90초 동안 떠요(하루 한 번). 시각은 설정 탭이나 트레이의 알림 시간에서 바꿔요.
  • 커서 바라보기: 서 있거나 엎드려 있을 때 마우스가 가까이서 움직이면 옆으로 앉아 커서를 봐요. 커서가 위에 있으면 고개를 들어요. 커서 좌표는 읽기만 하고 어디에도 보내지 않아요.

창과 모니터

  • 창 옆면은 벽이에요. 걷다가 닿으면 기대고, 창 윗면은 올라설 수 있는 바닥, 창 아랫면은 점프할 때 부딪히는 천장이에요.
  • 최대화된 창처럼 하나가 들어갈 틈이 없는 창은 배경으로 쳐요. 그 위에서 평소처럼 지내요.
  • 다른 창 뒤에 가려진 부분은 없는 것으로 쳐요. 예를 들어 최대화한 메일 창 뒤에서 옆 모니터로 삐져나온 브라우저는 보이는 부분에만 기대요.
  • 모니터 사이: 디스플레이 설정에서 맞닿아 있는 모니터끼리는 걸어서 오가요. 바닥 높이가 달라도 돼요 — 낮으면 걸어 내려가 착지하고, 높으면 뛰어올라 계속 걸어요. 위아래로 쌓인 배치나 떨어진 배치는 드래그로만 옮길 수 있어요.
  • 모니터마다 배율(100 / 125 / 150%)이 달라도 각 모니터의 배율에 맞춰 크기가 맞춰져요.

집중 모드 (방해 금지)

  • 켜면 즉시 조용해져요. 몸 주변 24px 여유까지 어떤 창과도 겹치지 않는 바닥 자리 중 가장 가까운 곳으로 옮겨 엎드려요.
  • 그런 자리가 없으면(창이 화면을 다 덮으면) 잠시 숨어요. 0.5초마다 다시 살피고, 빈 자리가 1.5초 이상 유지되면 돌아와요. 돌아올 때 다른 창의 포커스를 뺏지 않아요.
  • 끄면 빈 자리 중 한 곳으로 돌아와요. 숨어 있는 동안에도 끄기는 바로 반영돼요.
  • 급하게 부르고 싶으면 트레이의 작업 표시줄 위로 데려오기 — 집중 모드를 끄고 바로 불러요.

Windows 시작 시 자동 실행

  • 트레이 메뉴나 설정 탭에서 Windows 시작 시 자동 실행을 켜면, 로그인할 때 하나가 스스로 켜져요. 관리자 권한은 필요 없어요(현재 사용자의 시작 프로그램 목록에 등록돼요).
  • 등록되는 건 지금 실행 중인 하나의 파일 경로예요. 설치한 하나에서 켜 주세요. 개발 실행 중에 켜면 그 개발용 파일이 등록돼요.
  • Windows 설정 → 앱 → 시작 프로그램에서도 Hana Forever 항목으로 보이고, 거기서 꺼도 돼요.

문제 해결

하나가 안 보여요
집중 모드에서 빈 자리가 없으면 숨어요. 트레이 → 작업 표시줄 위로 데려오기를 누르거나 창을 조금 치워 주세요. 다른 모니터 바닥에 있을 수도 있어요.
클릭이 하나를 그냥 통과해요
클릭 통과를 켠 상태예요. 트레이 → 액션 패널 열기/닫기 또는 작업 표시줄 위로 데려오기로 해제돼요.
화살표 키나 Space가 안 먹어요
하나를 한 번 클릭해서 포커스를 준 뒤 눌러 주세요. 다른 창을 쓰는 동안엔 키를 가로채지 않아요.
모니터 사이를 못 건너요
디스플레이 설정에서 두 모니터가 옆으로 맞닿아 있어야 해요. 위아래로 놓였거나 사이가 떨어져 있으면 드래그로 옮겨 주세요.
아무것도 없는 곳에서 기대고 있어요
보이지 않는 창(투명 오버레이 등)이 있을 때 생기던 현상이에요. 클릭 통과 오버레이와 투명 창은 이제 무시하지만, 다시 보이면 개발 실행 창의 [hana] lean on … 줄에 어떤 창인지 남아요.
다른 PC에 설치하기
설치 파일(Hana Forever_x64-setup.exe)을 실행하면 돼요. Windows 10 이상 64비트, 관리자 권한 불필요. 처음엔 SmartScreen 경고가 뜰 수 있어요 — 추가 정보 → 실행. WebView2 런타임이 없으면 설치 중 자동으로 함께 설치돼요(그때만 인터넷 필요).
